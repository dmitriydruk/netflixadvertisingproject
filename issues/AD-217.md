# AD-217: Valid campaign returns no-fill at its end-time boundary

## Summary

A campaign configured to remain active through 10:00:00 is rejected when an ad request arrives at exactly 10:00:00. The decision is incorrectly recorded as `no_fill`.

## Expected behavior

For this synthetic service, the campaign window is inclusive at both ends:

```text
starts_at <= request_time <= ends_at
```

A campaign must be eligible at its exact `ends_at` timestamp, provided it is enabled and the request is not after that timestamp.

## Acceptance criteria

- A request before the end time is eligible.
- A request exactly at the end time is eligible.
- A request after the end time is not eligible.
- Disabled campaigns remain ineligible.
- Add a regression test for the exact end-time boundary.
- Keep the change limited to this eligibility defect.
